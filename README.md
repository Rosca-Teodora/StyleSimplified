## StyleSimplified: Apparel Management & Recommendation System

StyleSimplified is a standalone Java desktop application designed to digitize personal wardrobe management. 
It serves as a local inventory system and recommendation engine, allowing users to catalog their clothing, assemble and rate specific outfits, 
and filter their wardrobe based on dynamic attributes like weather, style, and occasion.

### Tech Stack:
- Backend: Java (Core logic, Collections API, OOP Principles)
- Frontend: JavaFX (MVC Architecture)
- Database: SQLite (JDBC)
- Build Tool: Maven
